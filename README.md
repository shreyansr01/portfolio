> Personal software engineering portfolio and project showcase.

## Features

- **Projects & Stories:** Live demos, repos, and overlay cards sharing the personal motivation behind each project.
- **Connected Timeline:** Engineering journey with links that jump and scroll directly to featured projects.
- **Skills Matrix:** Grouped stack spanning Backend, Data & Infra, Developer Tools, and CS Foundations.
- **Resume Viewer:** In-app PDF modal to preview and download the resume on-page.
- **Theme Engine:** Clean dark and light modes with instant local storage persistence.

---

## Tech Stack

- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, Framer Motion
- **Hosting:** Vercel

---

## Getting Started

```bash
git clone https://github.com/shreyansr01/portfolio.git
cd portfolio
npm install
npm run dev
```
